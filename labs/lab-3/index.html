Lab 3 — Falhas e watchdog

Um medidor de distância com sensor ultrassônico e display LCD funciona bem na bancada, até que um fio solta. Você vai provocar duas falhas (o sensor para de responder e o LCD perde a alimentação), ver o que a versão ingênua faz, escrever a versão que detecta e se recupera e, por fim, colocar o watchdog como rede de segurança contra travamentos.

O problema: o que acontece quando um fio solta?

O programa só enxerga números e respostas do barramento. Se ninguém verifica, uma falha física vira um dado errado tratado como verdade ou um programa travado. Neste lab, cada falha tem uma resposta no código:

Falha 1 · Sensor

O sensor para de responder. Sem limite de espera, pulseIn() fica até 1 s esperando o eco e devolve 0, que o LCD mostra como “0 cm”.

Resposta: timeout + validação por faixa + falha só depois de 3 leituras ruins seguidas.

Falha 2 · LCD

O display perde a alimentação. Ao voltar, ele precisa ser reinicializado; sem isso, fica com quadrados pretos. O barramento I²C também pode travar o programa.

Resposta: verificar o ACK do I²C a cada segundo e reinicializar quando o LCD voltar.

Rede de segurança · WDT

E se o código travar por um motivo que ninguém previu? O watchdog é um temporizador de hardware que reinicia o chip se o loop() parar de avisar que está vivo.

Resposta: wdt_reset() em um único ponto, no fim do loop.

Conteúdo da Aula 3 usado aqui: validação de leituras (slide 17), verificação de I²C (slide 19), millis() e timeouts (slide 20), watchdog (slides 21 e 22) e buffers fixos com snprintf() (slide 7).

O circuito na bancada

O sensor ultrassônico HC-SR04 usa dois pinos digitais: D9 dispara a medição (TRIG) e D10 recebe o eco (ECHO). O LCD 16×2 com módulo I²C usa só dois fios de dados: SDA em A4 e SCL em A5. Os dois são alimentados pelo 5 V do Arduino.

Preparando a Arduino IDE

  1. Monte o circuito, conecte o Arduino pela USB e selecione a placa Arduino Uno e a porta.
  2. Em Ferramentas → Gerenciar bibliotecas, instale LiquidCrystal I2C (de Frank de Brabander).
  3. Em Ferramentas → Placa → Gerenciador de placas, confira se Arduino AVR Boards está na versão 1.8.3 ou mais nova: a função Wire.setWireTimeout() da Parte B só existe a partir dela.
  4. Se o LCD acender mas não mostrar texto, gire o trimpot azul atrás do módulo (contraste). Se continuar sem texto, troque o endereço 0x27 por 0x3F no código.
  5. Abra o Monitor Serial em 9600 baud.

Parte A

A versão ingênua

Este código mede a distância e mostra no LCD. Ele funciona na bancada, mas não verifica nada. Além da distância, a serial mostra quanto tempo cada volta do loop() levou.

sketch.ino · Parte A
// Lab 3 — Parte A: versão ingênua (nenhuma verificação de falha)
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

const int PINO_TRIG = 9;
const int PINO_ECHO = 10;

LiquidCrystal_I2C lcd(0x27, 16, 2);   // endereço 0x27 (alguns módulos usam 0x3F)

void setup() {
  pinMode(PINO_TRIG, OUTPUT);
  pinMode(PINO_ECHO, INPUT);
  Serial.begin(9600);
  lcd.init();
  lcd.backlight();
}

void loop() {
  unsigned long inicio = millis();

  // pulso de 10 µs no TRIG dispara uma medição
  digitalWrite(PINO_TRIG, LOW);  delayMicroseconds(2);
  digitalWrite(PINO_TRIG, HIGH); delayMicroseconds(10);
  digitalWrite(PINO_TRIG, LOW);

  unsigned long eco = pulseIn(PINO_ECHO, HIGH);   // espera o eco voltar
  unsigned int cm = eco / 58;                      // 58 µs por cm (ida e volta)

  lcd.setCursor(0, 0);
  lcd.print("Dist: ");
  lcd.print(cm);
  lcd.print(" cm    ");

  Serial.print(cm);
  Serial.print(" cm   volta do loop = ");
  Serial.print(millis() - inicio);
  Serial.println(" ms");

  delay(250);
}

Provoque as duas falhas

  1. Funcionando: aponte o sensor para a sua mão a uns 20 cm e anote a volta do loop na serial.
  2. Falha 1, sensor: solte o fio do TRIG (D9). O sensor nunca é disparado, então o eco nunca vem. Observe o LCD e a volta do loop. Reconecte o fio.
  3. Falha 2, LCD: solte o fio VCC do LCD por uns 3 s e reconecte. Observe o display e se a serial continua andando.

O display mostra 0 cm como se fosse uma medida real, e a volta do loop passa de ~1 250 ms: o pulseIn() ficou 1 s esperando.

Parte B

Detectar e se recuperar

A Parte B resolve as duas falhas sem reiniciar a placa. São quatro mudanças:

MudançaComoPor quê
Timeout no ecopulseIn(ECHO, HIGH, 30000)Espera no máximo 30 ms, e não 1 s. Sem eco, devolve 0.
ValidaçãoFora de 2 a 400 cm = suspeita; 3 seguidas = falha confirmadaUma leitura ruim isolada pode ser ruído e não gera alarme.
LCD verificadoWire.endTransmission() == 0 a cada 1 s; ao voltar, lcd.init()O I²C confirma cada envio com ACK. Sem ACK, o LCD não está lá.
Sem delay()millis(): sensor a cada 250 ms, LCD a cada 1 s; I²C com timeout de 25 msNenhuma espera prende o loop().

As linhas do LCD são montadas em char buf[17]: 16 colunas + o '\0', com snprintf(), sem String. O formato %-16s completa a linha com espaços e apaga o que sobrou da mensagem anterior.

sketch.ino · Parte B
// Lab 3 — Parte B: detecção de falhas no sensor e no LCD
#include <Wire.h>
#include <LiquidCrystal_I2C.h>

const int PINO_TRIG = 9;
const int PINO_ECHO = 10;
const uint8_t ENDERECO_LCD = 0x27;

const unsigned long TIMEOUT_ECO = 30000;   // µs: espera máxima pelo eco
const unsigned int DIST_MIN = 2;           // cm: faixa útil do HC-SR04
const unsigned int DIST_MAX = 400;
const int SUSPEITAS_PARA_FALHA = 3;        // leituras ruins seguidas = falha
const unsigned long INTERVALO_SENSOR = 250;   // ms
const unsigned long INTERVALO_LCD = 1000;     // ms

LiquidCrystal_I2C lcd(ENDERECO_LCD, 16, 2);

bool sensorOk = true;
int suspeitas = 0;
unsigned int ultimaBoa = 0;     // último valor válido, em cm
bool lcdOk = false;
unsigned long antesSensor = 0;
unsigned long antesLcd = 0;

// Registro: [instante] nível ORIGEM: mensagem   (I info · W aviso · E erro)
void registrar(char nivel, const char* origem, const char* msg) {
  Serial.print('[');
  Serial.print(millis());
  Serial.print("] ");
  Serial.print(nivel);
  Serial.print(' ');
  Serial.print(origem);
  Serial.print(": ");
  Serial.println(msg);
}

// ---------- Sensor ----------
unsigned int medirCm() {                    // devolve 0 se o eco não voltar
  digitalWrite(PINO_TRIG, LOW);  delayMicroseconds(2);
  digitalWrite(PINO_TRIG, HIGH); delayMicroseconds(10);
  digitalWrite(PINO_TRIG, LOW);
  unsigned long eco = pulseIn(PINO_ECHO, HIGH, TIMEOUT_ECO);
  return eco / 58;
}

void lerSensor() {
  unsigned int cm = medirCm();
  bool valida = cm >= DIST_MIN && cm <= DIST_MAX;

  if (valida) {
    suspeitas = 0;
    ultimaBoa = cm;
    if (!sensorOk) {
      sensorOk = true;
      registrar('I', "SENSOR", "voltou a responder");
    }
  } else if (sensorOk) {
    suspeitas++;                            // 1 leitura ruim = suspeita
    registrar('W', "SENSOR", "leitura suspeita");
    if (suspeitas >= SUSPEITAS_PARA_FALHA) {
      sensorOk = false;                     // 3 seguidas = falha confirmada
      registrar('E', "SENSOR", "falha confirmada");
    }
  }
}

// ---------- LCD ----------
void iniciarLcd() {
  lcd.init();
  lcd.backlight();
  Wire.setWireTimeout(25000, true);         // I2C nunca espera mais que 25 ms
}

bool lcdPresente() {
  Wire.beginTransmission(ENDERECO_LCD);
  return Wire.endTransmission() == 0;       // 0 = o módulo respondeu (ACK)
}

void escreverLinha(uint8_t linha, const char* texto) {
  char buf[17];                             // 16 colunas + '\0'
  snprintf(buf, sizeof(buf), "%-16s", texto);   // completa com espaços
  lcd.setCursor(0, linha);
  lcd.print(buf);
}

void atualizarLcd() {
  if (!lcdPresente()) {
    if (lcdOk) registrar('E', "LCD", "sem resposta no I2C");
    lcdOk = false;
    return;                                 // o resto do sistema continua
  }
  if (!lcdOk) {                             // acabou de voltar: reinicializa
    iniciarLcd();
    lcdOk = true;
    registrar('I', "LCD", "reconectado e reinicializado");
  }

  char texto[17];
  if (sensorOk) snprintf(texto, sizeof(texto), "Dist: %u cm", ultimaBoa);
  else          snprintf(texto, sizeof(texto), "Dist: --- cm");
  escreverLinha(0, texto);
  escreverLinha(1, sensorOk ? "Sensor: OK" : "Sensor: FALHA");
}

void setup() {
  pinMode(PINO_TRIG, OUTPUT);
  pinMode(PINO_ECHO, INPUT);
  Serial.begin(9600);
  Wire.begin();
  Wire.setWireTimeout(25000, true);
  registrar('I', "SISTEMA", "iniciado");
}

void loop() {
  unsigned long agora = millis();

  if (agora - antesSensor >= INTERVALO_SENSOR) {
    antesSensor = agora;
    lerSensor();
  }
  if (agora - antesLcd >= INTERVALO_LCD) {
    antesLcd = agora;
    atualizarLcd();
  }
}

Teste de aceitação: com o TRIG solto, o LCD mostra Sensor: FALHA em até 2 s e a serial registra E SENSOR. Ao reconectar, volta para OK sozinho. Ao religar o LCD, ele volta a mostrar texto em até 2 s, sem reset e sem a serial parar.

Parte C

Watchdog: a rede de segurança

As Partes A e B trataram as falhas que nós previmos. O watchdog cuida das que ninguém previu: um laço infinito, uma biblioteca que trava, memória corrompida. Ele é um temporizador de hardware que conta até 2 s; o programa precisa zerá-lo (wdt_reset()) antes disso. Se o loop() travar e parar de zerar, o chip reinicia sozinho.

Ligar

wdt_enable(WDTO_2S) no fim do setup(), depois da inicialização.

Alimentar

wdt_reset() em um único ponto: o fim de uma volta completa do loop().

Registrar

Um contador de boots na EEPROM sobrevive ao reset e mostra quantas vezes a placa reiniciou.

O código é a Parte B com as linhas marcadas // WDT. Para testar, ele trava de propósito quando você envia a letra t pelo Monitor Serial.

sketch.ino · Parte C
// Lab 3 — Parte C: Parte B + watchdog
// Só as diferenças em relação à Parte B estão comentadas com  // WDT
#include <Wire.h>
#include <LiquidCrystal_I2C.h>
#include <avr/wdt.h>        // WDT
#include <EEPROM.h>         // WDT: contador de boots que sobrevive ao reset

const int PINO_TRIG = 9;
const int PINO_ECHO = 10;
const uint8_t ENDERECO_LCD = 0x27;

const unsigned long TIMEOUT_ECO = 30000;
const unsigned int DIST_MIN = 2;
const unsigned int DIST_MAX = 400;
const int SUSPEITAS_PARA_FALHA = 3;
const unsigned long INTERVALO_SENSOR = 250;
const unsigned long INTERVALO_LCD = 1000;

LiquidCrystal_I2C lcd(ENDERECO_LCD, 16, 2);

bool sensorOk = true;
int suspeitas = 0;
unsigned int ultimaBoa = 0;
bool lcdOk = false;
unsigned long antesSensor = 0;
unsigned long antesLcd = 0;
uint16_t boots = 0;         // WDT

void registrar(char nivel, const char* origem, const char* msg) {
  Serial.print('[');
  Serial.print(millis());
  Serial.print("] ");
  Serial.print(nivel);
  Serial.print(' ');
  Serial.print(origem);
  Serial.print(": ");
  Serial.println(msg);
}

unsigned int medirCm() {
  digitalWrite(PINO_TRIG, LOW);  delayMicroseconds(2);
  digitalWrite(PINO_TRIG, HIGH); delayMicroseconds(10);
  digitalWrite(PINO_TRIG, LOW);
  unsigned long eco = pulseIn(PINO_ECHO, HIGH, TIMEOUT_ECO);
  return eco / 58;
}

void lerSensor() {
  unsigned int cm = medirCm();
  bool valida = cm >= DIST_MIN && cm <= DIST_MAX;
  if (valida) {
    suspeitas = 0;
    ultimaBoa = cm;
    if (!sensorOk) {
      sensorOk = true;
      registrar('I', "SENSOR", "voltou a responder");
    }
  } else if (sensorOk) {
    suspeitas++;
    registrar('W', "SENSOR", "leitura suspeita");
    if (suspeitas >= SUSPEITAS_PARA_FALHA) {
      sensorOk = false;
      registrar('E', "SENSOR", "falha confirmada");
    }
  }
}

void iniciarLcd() {
  lcd.init();
  lcd.backlight();
  Wire.setWireTimeout(25000, true);
}

bool lcdPresente() {
  Wire.beginTransmission(ENDERECO_LCD);
  return Wire.endTransmission() == 0;
}

void escreverLinha(uint8_t linha, const char* texto) {
  char buf[17];
  snprintf(buf, sizeof(buf), "%-16s", texto);
  lcd.setCursor(0, linha);
  lcd.print(buf);
}

void atualizarLcd() {
  if (!lcdPresente()) {
    if (lcdOk) registrar('E', "LCD", "sem resposta no I2C");
    lcdOk = false;
    return;
  }
  if (!lcdOk) {
    iniciarLcd();
    lcdOk = true;
    registrar('I', "LCD", "reconectado e reinicializado");
  }
  char texto[17];
  if (sensorOk) snprintf(texto, sizeof(texto), "Dist: %u cm", ultimaBoa);
  else          snprintf(texto, sizeof(texto), "Dist: --- cm");
  escreverLinha(0, texto);
  escreverLinha(1, sensorOk ? "Sensor: OK" : "Sensor: FALHA");
}

void setup() {
  MCUSR = 0;                // WDT: limpa o motivo do último reset
  wdt_disable();            // WDT: desligado durante a inicialização

  pinMode(PINO_TRIG, OUTPUT);
  pinMode(PINO_ECHO, INPUT);
  Serial.begin(9600);
  Wire.begin();
  Wire.setWireTimeout(25000, true);

  EEPROM.get(0, boots);     // WDT: quantas vezes a placa já ligou
  if (boots == 0xFFFF) boots = 0;           // EEPROM nova vem com 0xFFFF
  boots++;
  EEPROM.put(0, boots);

  char msg[20];
  snprintf(msg, sizeof(msg), "boot #%u", boots);
  registrar('I', "SISTEMA", msg);

  wdt_enable(WDTO_2S);      // WDT: sem wdt_reset() por 2 s, o chip reinicia
}

void loop() {
  unsigned long agora = millis();

  if (agora - antesSensor >= INTERVALO_SENSOR) {
    antesSensor = agora;
    lerSensor();
  }
  if (agora - antesLcd >= INTERVALO_LCD) {
    antesLcd = agora;
    atualizarLcd();
  }

  // WDT: teste de travamento. Digite t no Monitor Serial e tecle Enter.
  if (Serial.available() && Serial.read() == 't') {
    registrar('W', "TESTE", "travando o loop de proposito");
    while (true) { }        // laço infinito: só o watchdog tira daqui
  }

  wdt_reset();              // WDT: "estou vivo", um único ponto, no fim da volta
}

Testes

  1. Travamento: anote o número do boot na serial (I SISTEMA: boot #N). Digite t e tecle Enter. A serial para, e em ~2 s a placa reinicia com boot #N+1.
  2. Alimentando no lugar errado: troque while (true) { } por while (true) { wdt_reset(); }, grave e repita o teste. O que acontece agora? (É a Pergunta 3 da aula.)
  3. As falhas da Parte B continuam tratadas: solte o TRIG e religue o LCD. Nenhuma delas deve provocar reset: o watchdog é a última linha de defesa, não a primeira.
Se a placa ficar reiniciando sem parar logo após gravar, ela tem um bootloader antigo que não desliga o watchdog. Isso não acontece no Uno R3 original; em clones, avise o professor.

Identificação
1 Contextualizar

Antes de mexer no código, escreva com suas palavras:

  • o objetivo: um medidor de distância que detecta a falha do sensor e do LCD e se recupera sem intervenção;
  • o comportamento esperado: leitura ruim isolada é ignorada; 3 seguidas mudam o estado para FALHA; o LCD religado volta sozinho; um travamento do loop reinicia a placa;
  • o critério de aceitação: os testes de aceitação das Partes B e C (FALHA em até 2 s, LCD de volta em até 2 s sem reset, reset pelo WDT em ~2 s);
  • o que você vai delegar à IA e o que pretende fazer sozinho.
2 Consultar

Faça à IA uma pergunta delimitada sobre um ponto que você não domina. Uma pergunta delimitada pede explicação ou hipótese, não o código pronto. Exemplos:

  • “Por que pulseIn() pode deixar o loop() lento, e o que muda com o terceiro parâmetro?”
  • “O que significam os valores que Wire.endTransmission() devolve?”
  • “Por que alimentar o watchdog dentro de um laço de espera é um erro?”
3 Confrontar

Escolha uma afirmação técnica da resposta e confira contra uma fonte primária:

  • a documentação do pulseIn() (timeout padrão de 1 s) e do Wire.endTransmission() (códigos de retorno);
  • a documentação da avr-libc para <avr/wdt.h> (wdt_enable, wdt_reset, tempos WDTO_*);
  • o datasheet do HC-SR04: faixa de 2 a 400 cm e distância = tempo do eco ÷ 58 (em µs, para cm);
  • o seu próprio teste na bancada: a volta do loop, o log da serial e o contador de boots.

Diga se a afirmação se confirmou, precisou de ajuste ou estava errada, citando o trecho da fonte ou o resultado do teste. Se você rejeitou ou corrigiu uma sugestão, ela vira o seu ADR (registro de decisão).

Rode as três partes na bancada e registre o que você mediu e observou.

5 Comprovar sem IA
